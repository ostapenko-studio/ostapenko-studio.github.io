简短版本

UV Index 显示你所在位置的当前紫外线指数和紫外线指数预报。它在设计时就 以尽可能少地收集数据为目标。

  • 没有账户，没有注册，没有分析统计，没有崩溃报告，我们也不运行任何服务器。 我们完全不掌握关于你的个人信息。
  • 有三样东西会离开你的设备，而它们都不会到我们这里：你的 大致坐标会发送给天气数据提供方以获取预报，也会发送给你手机的 操作系统以转换成城镇名称；在免费版本中，设备信息和广告信息 会发送给 Google 以投放横幅广告。
  • 你的坐标在发送到任何地方之前，都会被刻意四舍五入到小数点后两位 （约 1.1 公里）。紫外线的变化以数十公里为尺度，因此更高的精度毫无 用处，我们也不发送它。
  • 广告以非个性化方式请求，并且在任何广告能够加载之前， 本应用会将 Google 置于受限广告模式——没有个性化，也不会使用 广告标识符来给你建画像。不存在同意表单，因为并不存在需要征得同意的个性化。 购买去除广告会完全停止广告请求。
  • 你的设置、你缓存的预报、你的提醒和你的主屏幕小组件都留在你的设备上。 删除应用即会删除它们。

本页其余部分详细说明上述全部内容，包括谁接收什么、依据什么法律依据、 发往哪些国家，以及你拥有哪些权利。

关于位置，说得直白些

本应用向你的操作系统请求你的大致（粗略）位置——它从不请求 精确定位。在你的坐标被发送到任何地方之前，它们会被四舍五入到小数点后两位， 大约 1.1 公里。这种四舍五入是刻意的数据最小化：紫外线预报的网格远比一公里 粗糙，因此多余的位数只会告诉第三方你在哪里，而不会告诉应用任何它需要的信息。

位置功能在你开启之前是关闭的。在你于操作系统的提示中授予 位置权限之前，应用无法读取你的位置，而且你随时可以在设备设置中撤回该权限。 法律并不要求你提供位置信息，我们也不要求——但如果你拒绝，应用就无法显示你 所在位置的紫外线指数。

本应用不追踪你的行动轨迹，不在后台运行，也不会建立任何关于你去过哪里的 历史记录。

关于城镇名称的一处更正

本政策的早期版本曾说城镇或城区名称是「在你的设备上」解析的。那是错的， 我们已经改正。应用请求操作系统把坐标转换成地名，而在 iOS 和 Android 上， 这项查询都是通过网络完成的：你的坐标被发送给 Apple 或 Google， 然后返回一个地名。我们宁愿把话说清楚，也不愿让一句代码并不支持的、听着让人 安心的句子继续留在这里。

我们从不接收的信息

我们——Ostapenko Studio——从不接收、存储或记录你的位置、 你的设备标识符或你的 IP 地址。这是关于我们的陈述，而不是关于表中所列第三方 的陈述；那些第三方会直接从你的设备接收表中所说的内容。

广告，以及其依据

免费版本显示一条由 Google AdMob 投放的横幅广告。广告以非个性化 方式请求：我们不会基于你的兴趣或基于关于你的画像来请求广告，我们也不会使用 你的位置来定向投放广告。

此外，在任何广告能够加载之前，本应用会以原生方式将 Google 置于 受限广告模式。不会使用任何广告标识符来构建关于你的画像， 并且全球任何地方都不会显示同意表单，因为并不存在需要征得 同意的个性化。

投放广告仍然意味着 Google 的广告 SDK 会在你的设备上存储或读取信息，并接收 设备信息和你的 IP 地址。Google 会在设备上存储少量信息，以检测无效和欺诈性的 广告流量，并使用 IP 地址来投送广告。我们对此的法律依据是正当利益 ：为不购买去除广告的人保持本应用免费。你可以对此提出反对，而去除广告 会彻底终止这件事。

Google 还声明，它可能出于广告目的根据你的 IP 地址估算你的大致位置。该估算 是 Google 所做的，与上文所述的坐标无关，而且无论你是否已授予应用位置权限， 它都会发生。

这一切由你掌控：

  • 你随时可以对这项处理提出反对——请使用本政策末尾的 联系方式写信给我们。
  • 你设备自身的广告控制（重置或限制广告标识符）同样适用。
  • 购买去除广告会完全停止广告请求——广告 SDK 不再发出任何 请求，Google 通过本应用进行的收集也随之停止。

当你使用本应用时，广告提供方可能会随时间推移、跨不同的应用和服务 收集有关你活动的信息。我们自己不做这件事，除了汇总收入之外，我们不 从中获得任何东西。

我们会出售或分享你的信息吗？

作为事实而非法律结论陈述：我们不接收关于你的任何个人信息，所以我们没有 任何可以出售的东西。广告以非个性化方式请求。广告提供方在上述依据之下， 直接从你的设备接收设备信息、你的 IP 地址和一个广告标识符。 我们只收到汇总收入。我们不会以交出关于你的信息来换取金钱——我们 获得的是广告收入。

Do Not Track

本应用不是网页浏览器，不会收到任何「Do Not Track」（请勿追踪）浏览器信号， 因此也不存在需要它响应的此类信号。我们不会跨其他应用或网站追踪你。在这里真正 有效的控制手段就是上文列出的那些：你设备的广告设置，以及去除广告。

购买

一次性的去除广告购买完全由 Apple 的 App Store 或 Google Play 处理，它们是 登记商户。我们从不会看到你的姓名、付款详情或账单信息。我们从商店只收到一项 确认购买存在的信息，正是它使应用得以隐藏横幅广告，并在你的其他设备上恢复 你的购买。

通知与小组件

可选的每日紫外线提醒由操作系统在你的设备本地安排。没有任何通知数据离开 你的设备，我们也没有能力向你发送推送消息。主屏幕小组件由已经缓存在你设备上 的预报绘制而成。

任何信息保留多久，以及如何销毁

  • 我们不保留任何内容。我们这边没有服务器、没有数据库、 没有日志文件，所以我们没有任何可以保留的东西，而我们的处理在你关闭应用时 即告结束。
  • 在你的设备上：你的设置会一直保留直到你更改它们；缓存的 预报在应用每次刷新时被覆盖。当你删除应用时，两者连同应用 存储的其他一切都会被销毁——这就是所有应用内数据的删除机制，而且它完全 掌握在你手中。
  • 第三方依据它们自己的政策保留它们所保留的内容，相关政策 链接见上表。

安全

我们的安全措施是有限的，因为我们的风险敞口也是有限的，而我们宁愿如实描述 它们，也不愿暗示更多。应用发出的每一个请求都通过 HTTPS 传输。我们不运行任何 服务器，也不掌握任何个人信息，因此我们这边不存在可供攻破的用户数据库。这里 没有账户，也没有密码。你设备上的数据由你设备自身的操作系统保护措施来保护。

自动化决策

不存在对你产生法律效果或类似重大影响的自动化决策，也不存在画像。应用根据 一个预报数值计算出一个紫外线等级，并在你设定了肤质类型的情况下平移该等级—— 那是显示在屏幕上给你看的算术，不是关于你所作出的决定。

儿童与青少年

UV Index 是一款面向普通大众的应用。它不面向儿童，其设计 也不以吸引儿童为目的，而且我们不会在知情的情况下收集儿童的个人信息。我们的 最低年龄立场是，本应用面向13 岁及以上的人群；在为同意设定 更高门槛的司法辖区——包括同时涵盖青少年和儿童的巴西，以及印度——低于该门槛 的人应仅在父母或监护人的参与下使用本应用。

由于本应用被年轻人在阳光下使用，无论使用者是谁，我们都以此要求自己：

  • 广告是非个性化的，并且没有画像。
  • 位置仅用于生成紫外线读数和地名。它从不 用于定向投放广告，也从不被我们保留。
  • 应用中没有任何设计是为了让你持续使用它——没有连续打卡记录，没有推动提示， 也没有促活通知。

本应用没有年龄门禁。如果你是父母或监护人，并且认为某位 儿童通过本应用提供了个人信息，请联系我们，我们会提供协助——不过，如上文所述， 我们没有任何可删除的内容，而删除应用会移除它所存储的一切。
