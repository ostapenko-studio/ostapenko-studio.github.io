簡短版本

UV Index 顯示你所在位置的目前紫外線指數與紫外線指數預報。它在設計時就 以盡可能少收集資料為目標。

  • 沒有帳戶，沒有註冊，沒有分析追蹤，沒有當機回報，我們也不營運任何伺服器。 我們完全不掌握關於你的個人資料。
  • 有三樣東西會離開你的裝置，而它們都不會到我們這裡：你的 大略座標會傳送給天氣資料提供方以取得預報，也會傳送給你手機的 作業系統以轉換成城鎮名稱；在免費版本中，裝置資訊與廣告資訊 會傳送給 Google 以放送橫幅廣告。
  • 你的座標在傳送到任何地方之前，都會刻意四捨五入到小數點後兩位 （約 1.1 公里）。紫外線的變化以數十公里為尺度，因此更高的精度毫無 用處，我們也不傳送它。

  • 你的設定、你快取的預報、你的提醒和你的主畫面小工具都留在你的裝置上。 刪除應用程式就會刪除它們。

本頁其餘部分詳細說明上述全部內容，包括誰接收什麼、依據什麼法律依據、 傳往哪些國家，以及你擁有哪些權利。

關於位置，說得直白些

本應用程式向你的作業系統請求你的大略（粗略）位置——它從不 請求精確定位。在你的座標被傳送到任何地方之前，它們會四捨五入到小數點後兩位， 大約 1.1 公里。這種四捨五入是刻意的資料最小化：紫外線預報的網格遠比一公里 粗糙，因此多餘的位數只會告訴第三方你在哪裡，而不會告訴應用程式任何它需要的 資訊。

位置功能在你開啟之前是關閉的。在你於作業系統的提示中授予 位置權限之前，應用程式無法讀取你的位置，而且你隨時可以在裝置設定中撤回該權限。 法律並不要求你提供位置資訊，我們也不要求——但如果你拒絕，應用程式就無法顯示 你所在位置的紫外線指數。

本應用程式不追蹤你的行動軌跡，不在背景執行，也不會建立任何關於你去過哪裡 的歷史紀錄。

關於城鎮名稱的一處更正

本政策的早期版本曾說城鎮或行政區名稱是「在你的裝置上」解析的。那是錯的， 我們已經改正。應用程式請求作業系統把座標轉換成地名，而在 iOS 和 Android 上， 這項查詢都是透過網路完成的：你的座標被傳送給 Apple 或 Google， 然後回傳一個地名。我們寧願把話說清楚，也不願讓一句程式碼並不支持的、聽著讓人 安心的句子繼續留在這裡。

我們——Ostapenko Studio——從不接收、儲存或記錄你的位置、 你的裝置識別碼或你的 IP 位址。這是關於我們的陳述，而不是關於表中所列第三方 的陳述；那些第三方會直接從你的裝置接收表中所說的內容。

廣告，以及其背後的同意

免費版本顯示一則由 Google AdMob 放送的橫幅廣告。廣告以非個人化 方式請求：我們不會依據你的興趣或依據關於你的剖析來請求廣告，我們也不會使用 你的位置來鎖定投放廣告。

即便放送非個人化廣告，也意味著 Google 的廣告 SDK 會在你的裝置上儲存或讀取 資訊，並接收裝置資訊、你的 IP 位址和一個廣告識別碼。由於這涉及在你的裝置上 儲存與存取資訊，其法律依據是同意——不是「正當利益」，也不是 廣告為非個人化這一事實。我們透過向歐洲經濟區、英國與瑞士的使用者顯示的應用 程式內 Google User Messaging Platform 提示來取得該同意。

Google 還聲明，它可能出於廣告目的依據你的 IP 位址推估你的大略位置。該推估 是 Google 所做的，與上文所述的座標無關，而且無論你是否已授予應用程式位置 權限，它都會發生。

這一切由你掌控：

  • 你隨時可以在設定 → 隱私權選項中變更或撤回你的同意。撤回 不影響在同意有效期間所做事情的合法性，而且你的撤回會被傳達給 Google。
  • 你裝置本身的廣告控制（重設或限制廣告識別碼）同樣適用。
  • 購買移除廣告會完全停止廣告請求——廣告 SDK 不再發出任何 請求，Google 透過本應用程式進行的蒐集也隨之停止。

當你使用本應用程式時，廣告提供方可能會隨時間推移、跨不同的應用 程式與服務蒐集有關你活動的資訊。我們自己不做這件事，除了彙總收益之外， 我們不從中獲得任何東西。

UV Index 是一款面向一般大眾的應用程式。它不以兒童為對象， 其設計也不以吸引兒童為目的，而且我們不會在知情的情況下蒐集兒童的個人資料。 我們的最低年齡立場是，本應用程式面向13 歲及以上的人；在為 同意設定更高門檻的司法管轄區——包括同時涵蓋青少年與兒童的巴西，以及印度—— 低於該門檻的人應僅在父母或監護人的參與下使用本應用程式。

  • 應用程式中沒有任何設計是為了讓你持續使用它——沒有連續紀錄，沒有推促提示， 也沒有促用通知。

本應用程式沒有年齡驗證關卡。如果你是父母或監護人，並且 認為某位兒童透過本應用程式提供了個人資料，請聯絡我們，我們會提供協助——不過， 如上文所述，我們沒有任何可刪除的內容，而刪除應用程式會移除它所儲存的一切。
